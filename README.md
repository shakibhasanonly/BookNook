# 📚 BookNook — Online Library Management

**Live Website:** https://book-nook-jet-ten.vercel.app/

BookNook is an online library management platform where users can explore books,
add their own books, borrow books, and manage their borrowed collections.

## ✨ Features

- 🔐 **User Authentication:** Register and log in using email/password or
  Google.
- 📖 **Browse Books:** Explore all available books with details.
- ➕ **Add Books:** Logged-in users can add new books to the library.
- ✏️ **Manage Books:** Edit and delete books added by the logged-in user.
- 📚 **Borrow Books:** Borrow available books and manage borrowing records.
- 🔄 **Return Books:** Return borrowed books and update available copies.
- 👤 **User Profile:** View profile information and manage your account.
- 🏠 **Dynamic Homepage:** Explore new arrivals and featured sections.
- 📱 **Responsive Design:** Enjoy the website on desktop, tablet, and mobile
  devices.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
- Express.js

## 🚀 Run Locally

```bash
git clone https://github.com/shakibhasanonly/BookNook.git
cd BookNook/client
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
